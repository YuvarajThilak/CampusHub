# CampusHub

CampusHub is a student platform that brings academics, campus life, collaboration, local services, transport, habits, and personal organization into one Flutter application.

## Phase 1

This project currently includes the base Flutter app, Material 3 theming, routing, onboarding, authentication screens, environment configuration, and a ready-to-extend architecture.

## Requirements

- Flutter 3.24+
- Dart 3.7+
- Android Studio or VS Code
- Supabase project
- Google Maps API key

## Setup

1. Copy `.env.example` to `.env` and fill in your values.
2. Run `flutter pub get`.
3. Run `flutter run`.

flutter pub get
flutter analyze
